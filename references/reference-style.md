A = `D:\CAPCUT\рилсики\10-…\output\анализ конкурентов.mp4`, B = `D:\CAPCUT\рилсики\11-мы-создали-ayugram\out\2 ролик (2).mp4`.

## Звук → `audio_profile: ref` (по умолчанию)
- Голос эталона = сырой тёмный микрофон без EQ/шумодава/Crisper: 4–6k −21, 6–8k −22, 8–12k −28 dB отн. 500–1k; −17…−18 LUFS, TP −1, крест 18–19.
- Монтажёр: вырезал паузы, ускорил **×1.10 с сохранением высоты**, выровнял куски, голос моно по центру, музыка/SFX стерео.
- Скилл: `voice_ref.match_fx` подгоняет спектр любого источника (скринкаст, микрофон) к `REF_BANDS` ±2 dB; финал −17.5 LUFS / TP −1; музыка −16 LU, входит после хука (`music_in`). Детали — shorts.md §5 «Профиль ref».
- Музыка: тёмная (выше 4 кГц на 17–26 dB ниже середины) — пад ~122 BPM (A) или бас-бит ~73 BPM (B). Хук A: 5 с без музыки, райзер + **полная тишина 0.4 с** перед панчлайном. Тик на каждом появлении текста/иконки (~1/с, серии 0.3–0.5 с). `refs/train/music/MUSIC_SFX_NOTES.md`.

## Цвет → `color_profile: ref` (по умолчанию)
- Look = честный декод HLG→709 (`SRC_VF`, npl=1000) + света прижаты (1.0→0.94, теплее), насыщенность ×0.985. LUT `assets/ref_joint.cube`, ошибка 4–7/255 на обоих роликах.
- **Temp −18 / Saturation 10 — наоборот от эталона.** Эталон тёплый в средних (R−G +18…+24, B−G −14…−18). CapCut-старт для длинного ролика: Temp 0, Tint 0, Exposure +2…+3, Contrast +4, Highlights −15…−20, Saturation −5; сверять рядом с кадром эталона.
- Остаток: поклиповая экспозиция (±0.3 EV) и зелёный LED микрофона — вручную/поклипово. Детали — shorts.md §1 «Профиль ref».

## Дизайн → `type: scheme` + правила ритма
- Палитра эталона: чёрный фон, тёплый градиент снизу #60260A, сетка белая 22 % шаг 108, текст #FBFBFB, цифры **жёлтые #F8DE03** со свечением, пунктир #E1E1E1. Шрифт — жирный гротеск строчными (у нас Unbounded, на 10–15 % шире).
- Схема «кто есть кто» — **полноэкранная вставка** (камера скрыта), узел всегда в одной точке (540, 860), мир переезжает к следующему узлу, дуга рисуется на переезде, узел pop 0.3 с, слово — 2–3 кадра в свой слот, фраза ≤ 1 с и cut. Реализовано: `scripts/shorts/scheme.py`, пример `assets/examples/specs/scheme_example.json`, shorts.md «Схема».
- Ритм: одно появление на одно слово (±1 кадр); новый субъект → новый узел + переезд; число → жёлтым крупно отдельной строкой; смена темы → смена ракурса камеры (не зум).
- На камере: без зумов, текст белый с тенью без плашки в пустом месте кадра, стикеры/мемы у плеч — не на лице. Ч/б кадр на 1 с + тишина как реакция (A).
- Отличия от бренда CLAUDE.md (оранжевый #D46A40, плашки, Unbounded) — `refs/train/design/DESIGN_NOTES.md` §7; какие правила менять — решает пользователь.
