# Рилс (Instagram, ≤ 30 с) из спеки шортса

Контекст: `scripts/shorts/build.py`, спека `specs/<id>.json`, формат и уроки — shorts.md (раздел «Рилсы»). Образец спеки с блоком `"reels"` — `assets/examples/specs/example.json`.

Шаги для каждого id:
1. `python -X utf8 scripts/shorts/build.py <id> --config config.json --plan` → `work/<id>/plan.json`: `words` (слово, start/end в секундах шортса), `pieces` (`s0`, `dur`, `tl0` — начало куска на таймлайне). Прочитать текст шортса целиком.
2. Выбрать ЯДРО: хук + главный тезис + вывод/пример. Выкинуть перечисления, оговорки, повторы, «кстати». Мысль не обрывать на полуслове. Речи ≤ 26 с (без ускорения, `speed` 1.0 — растяжение портит голос, shorts.md §5). Итог с концовкой 4 с — ≤ 30 с, жёсткое ограничение.
3. Перевести выбранные куски в таймлайн: tl = tl0 + (t_reel − s0) по нужному piece. Точные границы слов — из `build.load(...).words` (команда — shorts.md, раздел «Спека»). Начало диапазона — start первого слова −0.05, конец — end последнего +0.1.
4. В спеку — блок `"reels": {"ranges": [...]}` (+ `"code_word"`, иначе `reels_word` из config.json). В каждом range скопировать `zoom`/`keys`/`layout` из исходного range шортса, в который попадает отрезок (keys — только с `tl` внутри нового диапазона; первый ключ — состояние на входе). `cards` с `tl_in/tl_out` вне новых диапазонов → в `reels` свой `"cards": [...]` только с попадающими (или пустой список). hook как есть.
5. `python -X utf8 scripts/shorts/build.py <id> --reels` (≈5 мин). Затем текст `work/<id>/plan.json` words и `ffprobe -v error -show_entries format=duration -of csv=p=0 out/reels/<id>_*.mp4`. > 30 с (сборка сама останавливается после плана) или обрыв фразы → поправить диапазоны, пересобрать. build.py, shorts.css и чужие спеки не трогать.
6. Отчёт: id, длительность, итоговый текст, что выкинуто, LUFS/TP из вывода сборки.

Концовка 4 с: только крупные плашки «Напиши «СЛОВО» в комментариях / и я пришлю тебе / полный урок» — без мелкого кикера. Кодовое слово — на каждый ролик своё.
Первый рилс → ок пользователя → остальные.
Heredoc с длинным Python в bash на Windows ломается — патчи файлом в scratchpad или Edit.
