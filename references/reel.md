# Рилс с нуля: сырьё + сценарий → mp4 (без CapCut)

Когда: есть микрофон (m4a) и камера (MOV, iPhone HLG) по кускам сценария, нет проекта CapCut и нет длинного ролика.
Скрипт: `scripts/reel/build_reel.py <reel_spec.json>` (проверки — `scripts/reel/validate_reel.py`, вызываются в конце сборки).
Эталон — рилс монтажёра (references/reference-style.md): камера целиком, без зумов; текст белый с тенью без плашки в пустом месте
кадра; жёлтый акцент #F8DE03 со свечением; схема «кто есть кто» на весь экран (`scripts/shorts/scheme.py`); тёмные UI-экраны с
оранжевым; стикеры/мемы у плеч; тик на каждое появление; музыка после хука; голос ×1.20 с сохранением высоты (замерено по
рилсу монтажёра: слова в 1.2 раза короче, чем в микрофоне, высота та же; 64.7 с речи → 54.5 с).

## Вход
Папка со спекой (пути в спеке — от неё):
- `transcript/words.json` — `{файл: [{word, start, end}]}`, faster-whisper `word_timestamps=True` по КАЖДОМУ файлу голоса (и камеры — для сверки сдвига).
- `cam_offset` каждой секции: время камеры = время микрофона + cam_offset. Найти кросс-корреляцией огибающих (камера vs микрофон, 10-мс шаг) и проверить по 2–3 словам whisper на обоих файлах (расхождение ≤ 0.1 с).
- Голос — только микрофон; звук камеры не используется (сверка синхронизации и только).

- `script` — текст секции из сценария (обязательно). Слова субтитров берутся ИЗ СЦЕНАРИЯ, whisper даёт только времена:
  буквы whisper-слов получают время линейно внутри слова, буквы сценария сопоставляются с ними (difflib, блоки ≥ 2 букв),
  слово сценария = [первая, последняя] сопоставленная буква, несопоставленные (латиница: AyuGram, ChatGPT) — интерполяция
  между соседями. Без этого whisper пишет «аниме» вместо «а не мы», «Rayteo» вместо writelo. Все `at_word` и слова
  схемы — по тексту сценария. `caption_fix` после этого не нужен.
- `v` — отрезок(и) микрофона, с. Края ПРИВЯЗЫВАЮТСЯ К ЭНЕРГИИ (`speech_segments`: silencedetect −40 dB / 0.12 с):
  край внутри речи сдвигается наружу (начало — к началу сегмента −0.05 с, если до него ≤ 0.4 с, иначе к его концу —
  это вдох/фальстарт; конец — к концу сегмента +0.08 с). Паузы внутри режутся тоже по энергии, не по словам whisper:
  whisper занижает конец слова («бигтехов» 10.72 при речи до 11.32) и СКЛЕИВАЕТ ДУБЛИ (повтор фразы 15–24 с в CTA
  пропал из транскрипта) — по его временам фразы рвутся на полуслове. Проверка стыков: RMS 60 мс до/после каждого
  края ≤ −38 dB (скрипт в VALIDATION, «стыки»). Дубли выбирать по сегментам энергии и прослушкой кусков whisper'ом. секции идут подряд в порядке списка, между ними жёсткая склейка + вуш.
- `camera: null` — секция без камеры: её целиком закрывает непрозрачная графика (`scheme`, `ui_cards` или `footage`); под ней чёрный кадр.
- `footage` — полноэкранный футаж (`scripts/reel/footage.py`, фон как у схемы: градиент, дрейф сетки, дыхание). `kind: "survey"` — {total, part, label, at_total, at_part, at_clock, at_clock2, at_day, at_feed, at_punch, clock_text, day_text}: счётчик 0→total на слове at_total + сетка фигурок 5×N (тик на каждую), на at_part первые part загораются акцентом (кольцо-пульс), число → «part / total»; часы со стрелкой 12→1→2 на at_clock/at_clock2 + «1–2 Ч», «В ДЕНЬ» на at_day; телефон с бесконечно скроллящейся лентой на at_feed (вуш); панч scale 1.07 на at_punch. Субтитры поверх (cap_y 300). Сделан для 14/opros (v11) вместо плохой камеры.
- `angle` — пресет расположения текста, как у монтажёра — рядом с головой, не на лице и не на груди (`mic` — слева внизу у микрофона y 1330, по левому краю; `high` — над головой y 440; `arms` — над головой, мемы в верхних углах; `couch` — голова слева вверху → текст справа от неё y 400, по левому краю от x 430; КУРС y 1150 — нижние ~25 % кадра закрывает панель Reels, туда ничего не ставить). Без поля — по имени файла (`1`→mic, `2`→high, `cta`→couch, `img*`→arms, иначе high). Проверить по кадру каждой камеры: текст не на лице.
- Слова (`at_word`, `hook_until_word`, `label_words`, `phrases`, `pan_before_word`, `number.at_word`, `memes_out_word`, `cta_word`) — как в транскрипте секции (регистр и знаки не важны, совпадение по началу слова), ищутся по порядку — одно и то же слово дважды даёт следующее вхождение. Нет слова в транскрипте → для стикера предупреждение и конец секции, для схемы/мемов/CTA — ошибка.
- `accents` — слова жёлтым со свечением (подстрока с начала слова); `caption_fix` — замена слова в субтитре (whisper ослышался: `{"Юграм": "AyuGram"}`).
- `ui_cards` — тёмные макеты экранов (не скриншоты): `title`, `lines` (цифры → плитки, слова → строки), смена состояния каждую 1 с + тик; субтитр по одному слову под макетом.
- `memes` — две плитки 300 px с подписью (34 px) в верхних углах (y 250); `icon` — путь к фото (jpg/png, обрезка cover)
  или `dog`/`cat` (эмодзи-заглушка), `cap: true` — рисует академическую шапочку поверх. Pop на слове, уходят вместе
  (fade 0.2 с) на `memes_out_word`. Пока мемы на экране, обычный субтитр не показывается (подпись мема = субтитр),
  фраза, идущая в мемы, режется на их появлении. Фото: Wikimedia Commons API (`generator=search`, `gsrnamespace=6`),
  скачивать с User-Agent, иначе 403.
- `images` — иллюстрации/логотипы в секции с камерой: `{at_word, out_word?, src, x, y, w, h}`; `src` — путь к png/svg/jpg
  или встроенная `formula` (нейросеть + y = σ(Wx + b)). Ставить на ПУСТУЮ стену, не на голову: проверить кадр.
- Логотипы в схеме: `icon` — путь к png/svg от папки спеки (AyuGram: github AyuGram/AyuGramDesktop
  Telegram/Resources/art/icon512@2x.png; FunPay: funpay.com/img/layout/logo-funpay.svg — svg сохранять с расширением
  .svg, иначе браузер не рисует).
- `zoom` секции — `{scale: 1.0, to: 1.4, fx: 0.5, fy: 0.65}`: ЧИСТЫЙ плавный scale вокруг ФИКСИРОВАННОЙ точки (где лицо; от центра 0.5 лицо уезжало вниз) на всю секцию (14/opros). Пользователь (2026-10-28, трижды): никаких склеек между кадрировками, никакого слежения за лицом, никаких сдвигов кропа — «просто зумин, scale картинки плавный». Трекинг (`track: "face"`) в коде остался, НЕ включать. Быстрый punch-in на ударном слоге — `zooms: [{at_word, offset: 0.3×длина слова, scale 1.2, in 0.15, hold до конца, fx 0.5, fy 0.5}]` («по рабОте»). «Больше монтажа» = больше графики (`images`: `people10`/`people8`, `clock12`, `feed`), не движение камеры.
  Реализация — ОДИН `zoompan` на кусок (z = плавный scale × punch-in, x/y от `fx`/`fy` на каждом кадре). `scale,eval=frame` + `crop` не работает: crop берёт размер входа один раз при старте, точка привязки игнорируется (все punch-in'ы до 2026-10-28 были сломаны).
- `gap_max` / `gap_keep` секции — порог/остаток резки пауз внутри секции (хук 14: 0.2 / 0.1, глобально 0.35 / 0.15).
- `fisheye: {k1, k2}` секции — ffmpeg lenscorrection на камере (до zoompan, графика не искажается); хук 14 v13: k1 −0.45, k2 −0.15 — сильная бочка, центр увеличен, чёрных углов нет; zoom тогда слабее (to 1.15).
- `cap_y`, `cap_box` `[left, width, align]`, `cap_size` (px) секции — переопределить слот/размер субтитра пресета (длинное слово «индивидуально» при 46 px вылезало за кадр в desk-боксе 460 px → 520 px, 42 px).
- `pin_title` в секции со схемой — `{lines, at_word, y}`: термин (жёлтый, 2 строки) появляется на слове и висит до конца секции поверх схемы (z 6); y 460 — над иконкой узла (centre_y 870, радиус 202), выше — наезжает на хвосты текста предыдущих узлов.
- `device` в секции с камерой — `{frame, model, at_word, out_word?, x, y, w, screen?, logo?}`: макет телефона (iPhone 13 Pro Max, MockUPhone png `assets/devices/iphone13promax_{graphite,silver}.png`, 1684×3178, экран прозрачный 201,203 1284×2776, корпус 134,133 1414×2908). Вход: slide-up 140 px + pop от нижней кромки 0.45 с, экран загорается через 0.15 с, вуш. `screen` — png/mp4 в экран: видео режется в jpg-кадры (`<video>.frames_WxH/`, по кадру на кадр выхода, последний держится до out) и листается из `seek(t)` (SEQ_JS). Скринкаст сначала порезать `scripts/reel/screen_cut.py` (спека: сегменты in/out/speed, набор текста ×3–4, результаты в реальном времени ~1.2 с, xfade 0.15; 14 v21: три запроса за 5.5 с, кадры результатов брать когда превью уже загрузились), `logo` — плитка на тёмном экране. По центру, 85 % ширины, снизу: x 81, y 1000, w 918, `dist` 420, `dur` 0.5 — верх телефона под подбородком, низ за кадром; логотип на экране у верха видимой части (margin-top 22 %).
- `palette` (уровень спеки) — `{accent, text, cap_font, cap_size, cap_color, cap_upper}`: цвета/шрифт всего рилса. Writelo (14, v9): accent #D4683F, text #EDE8DE, субтитры Oswald 700 (узкий, вытянутый, кириллица; `assets/Oswald-var.ttf`; Bebas Neue с Google Fonts без кириллицы) 92 px, ВЕРХНИЙ регистр, оранжевые, тёмная обводка text-shadow (на светлой стене иначе не читается), акцентное слово — text-цвет + свечение. Перекрашивает и схему, и встроенные иллюстрации. Узкие боксы: service 60 px / [540,540], cta 76 px / [400,660]; opros cap_y 400, ряд фигурок y 680 (две строки субтитра при 92 px).
- `audio_profile` (уровень спеки) — `ref` (−17.5 LUFS, музыка −16) или `loud` (−14 LUFS, TP −1, музыка −18; 14 v15: «без наушников не слышно, что говорю»). Голос ВЫРАВНИВАЕТСЯ по секциям автоматически (`level_sections`: каждая секция меряется на voice_src и подтягивается к самой громкой; хук 14 был −33 LUFS против −21–25 у остальных). `denoise: true` секции — afftdn на дальнем/шумном дубле (хук 14: шум −46 dB против −83).
- Без хука: удалить секцию, `music_in: 0` (число = секунды); validate_reel окно голоса тогда с музыкой.
- `music_in` — `after_hook` (конец первой секции) или секунды выхода; `music_rel_lu` — музыка относительно голоса (−16).
- `reference` — рилс монтажёра для листа сравнения (не обязателен).

## Платформы (правила — shorts.md «Три платформы», tiktok.md)
Спека как написана = Instagram Reels (≤ 30 с, кодовое слово в голосовом CTA, карточки нет). Та же спека:
- `--youtube` → `out/youtube/<id>.mp4`: полная версия + карточка 2.5 с на затемнённом последнем кадре
  (`"youtube": {"end": {"kicker": "ПОЛНОЕ ВИДЕО", "line": "В ПРОФИЛЕ ↑"}}`), ≤ 60 с.
- `--tiktok` → `out/tiktok/<id>.mp4`: тизер — `"tiktok": {"sections": ["hook", "opros"]}` (хук + одна мысль) + карточка 2.5 с
  «Полное видео на YouTube: <канал>» (`tiktok_channel`, `tiktok_thumbnail` в спеке; нет → «ИЩИ ПО НАЗВАНИЮ ↑»), ≤ 15 с.
  `music_in: after:<секция>` вне тизера → после хука; `music_extra` чужих секций выкидывается.
Лимит превышен → сборка останавливается после плана. Карточка — последняя в DOM, затемнение накрывает всё (14 v22: «КУРС» просвечивал).

## Что делает сборка
1. План (`work/<id>/plan.json`, `wordmap.json`): паузы между словами > 0.35 с внутри секции режутся до 0.15 с; всё ×`speed`; времена выхода на сетке кадров; каждое слово → `start/end` в секундах выхода.
2. Голос: куски микрофона → concat → `atempo=1.2` (WSOLA; rubberband R2 на речи фазит/размазывает — «голос залупа») → компрессор `VOICE_COMP` (3.5:1, порог −21 dB — плотность эталона: LRA финала 4–5 LU, у эталона 4.1; без него 7.1) → `voice_ref.match_fx` на сжатом голосе (спектр эталона ±2 dB; 4–8 кГц выходит +2–3 dB, принято) → −17.5 LUFS до микса, моно по центру.
3. Видео: камера `SRC_VF + lut3d=assets/ref_joint.cube` → `TOYUV` 1080×1920 (поворот из метаданных MOV), без кропа и зумов; секции без камеры — чёрный.
4. Графика: одна страница `gfx.html` (shorts.css + anim.js, времена = секунды выхода) → Playwright → ProRes 4444 `gfx.mov` → overlay. Слово влетает снизу +30 px за 0.1 с в свой слот; фраза 1–4 слова, cut.
5. Звук: тик (пик −22 dBFS) на стикер/мем/число/узел схемы/смену UI/КУРС, вуш на склейку секций и переезды схемы; музыка с `music_in`, fade-in 0.3 с, `highshelf=g=-8:f=4000`, fade-out 1 с; финал через `build_render.final_loop` (−17.5 ±0.5 LUFS, TP ≤ −1.0 после AAC). H.264 CRF 18, AAC 192k.
6. Проверки → `work/<id>/VALIDATION.md`, `sheet.jpg` (1 кадр/с), `compare.jpg` (выход | эталон в 6 моментах), `check/*.png` (кадры до/на слове). Раздел «Что увидел» дописать руками по листам.

Флаги: `--plan` (без медиа: план, wordmap, gfx.html — открыть в браузере, `seek(t)`), `--gfx-only` (перерисовать графику и пересобрать), `--skip-gfx`, `--no-validate`.

## Заглушки и границы
- Иконки `ayugram` / `funpay` — силуэты из scheme.py; настоящие логотипы — путь к png/svg в `icon`.
- UI-экраны — макеты, не скриншоты продукта (нужны скриншоты сервиса от пользователя).
- Перед сборкой СПРОСИТЬ пользователя (монтажёр спрашивал): компании/логотипы для стикеров опыта (фриланс, стартапы,
  бигтех), скриншоты сервиса, какие мемы. Не ставить текстовые стикеры вместо логотипов молча.
- Один пресет положения текста на ракурс; жесты рук (CTA) могут пересечь текст на груди — смотреть лист.
- Whisper растягивает конец слова на паузу: автоматическая резка пауз находит мало; длинные паузы задавать границами `v`.
