# Саунд-дизайн

Замер референса: постоянная басовая подложка + плотные широкополосные удары и вуши на каждое движение.
Первая версия рилса 5 (29 щелчков с пиком −21 dBFS при голосе с пиками около 0 dBFS) была неслышна — «слабенький саунд-дизайн».
Версия со щелчком на КАЖДОЕ слово — «раздражает». Принятый вариант описан ниже.

## Принцип
Звук получает каждое движение (склейка, крупное слово, проп, лента, глаза), но не каждое слово субтитров.
Плотность: в среднем ≈ 2.5 звука на секунду ролика (45 на 18 с). Громкость задаётся пиком в dBFS до финальной нормализации
(голос в черновике: пики ≈ 0 dBFS, RMS ≈ −13.5).

| Движение | Звуки (`L.sfx(name, кадр, dB)`) |
|---|---|
| Жёсткая склейка секций | `cut_cam` / `cut_cam2` / `cut_click` −10 (чередовать); на переход к новой сцене + `thump` −13 |
| Слайд, переезд | `cut_long` −8, удар на середину движения |
| Крупное слово за головой | главное в ролике: `impact` −10 + `thump` −13; рядовое среди речи: `thump` −14 + `snap` −12; финальный призыв: `bell` −9 + `thump` −13 |
| Крупное слово поверх (не за головой) | `impact2` −9 + `shutter` −10 |
| Силуэт | `riser` −10 (заканчивается на первом кадре силуэта); на первом кадре `impact` −8 + `shutter` −10; лента `swish2` −12 на каждую половину; глаза `blip` −11 |
| Дьявол на силуэте | к звукам силуэта добавить `doom` −15 (низкий провал) на первый кадр и `glitch` −13 на рога |
| HUD | `focus` −12 на появление, `scan` −20 под ним |
| Акцентное слово курсивом | `accent` −7 (не больше 5–6 на ролик) |
| Кнопка-чип | появление `tact` −7, нажатие `ui` −5 + `mouse` −8 |
| Прокрутка | `swish3` −8, −11, −14 через 6 кадров |
| «Быстро», «резко» | `swish1` −9 |
| Лайк, понравилось, закладка | `ding` −9 / `ding2` −8 |
| Печать адреса | `typing` −6 на начало печати; подчёркивание и зачёркивание `swish2` −9 / −8 |
| Счёт, цифры | `counter` −12 |
| Крупная цифра-итог (69×, 61×) появляется | только `glitch2` −15 под визуальный глитч; БЕЗ `impact`/`thump` — «тудум» на каждой цифре раздражает (2026-11-18) |
| Одиночная клавиша | `keysolo` −6 |
| Счётчик (число бежит) | `counter` −12; сетка точек заполняется — `typing` −10 |
| Плитка загорается | появление ряда `tact` −7, выбор `ui` −5; зачёркивание ряда `swish2` −8 + `thump` −13 |
| График рисуется | `swish1` −10 на начало линии, `snap` −10 на каждый пик |
| Часы | `counter` −11 |
| Пункт списка с номером | `tact` −7 на каждый пункт |
| Каракули, рукописный текст | `marker` / `marker2` −9 на начало рисования (чередовать) |
| Светящаяся карточка | `impact2` −9 на первое слово, `thump` −12 на каждое следующее; под карточкой `doom` −16 |
| Стена-слово | `impact` −9 + `cut_long` −10 (удар на первый кадр стены) |
| Вспышка кадра | `flash` −10; двухцветный постер — `flash` −10 + `glitch2` −12 |
| Глитч-блоки | `glitch2` −11 на первый кадр, `glitch` −13 через 4 кадра |
| Контур человека | `focus` −11 + `swish1` −10 |
| Лесенка | `tact` −8 на каждое слово, на последнее (самое крупное) `thump` −12 |
| Строка промта | появление `swish2` −10, печать `typing` −7 |
| Слова россыпью | без звука на каждое слово; `accent` −7 только на акцентное |

Удары на крупных словах выходят примерно вровень с голосом, остальное на 5–15 dB тише — так одобрено.
Файлы, отрезок и точка удара каждого звука — словарь `S` в `scripts/captions/audio.py`. Пути там — от папки пака SFX:
`--sfx-dir <папка>` (запоминается в job.json проекта), иначе переменная `CAPTIONS_SFX_DIR`, иначе `"sfx_dir"` в `assets/captions/local.json`
(файл локальный, в репозиторий не входит). Сам пак в скилл не входит: другой пак — заменить файлы в `S`;
новый звук = новая строка там (длительность, пик и начало замерить; удар совместить с `at`).

Замер референса 2 (23.8 с): 91 атака звука ≈ 3.8 в секунду вместе с согласными речи, доля баса 15–37 % — плотность того же порядка,
что и принятая (≈ 2.5 звука на секунду без учёта речи); менять норму не нужно.

## Музыка
Трек выбирать под ролик из `assets/captions/music/` и передавать `--music` — НЕ ставить один и тот же трек в соседние ролики (Hyperfun во всех подряд пользователю надоел, 2026-11-17); без `--music` берётся Hyperfun. Нужен новый — скачать с incompetech.com и дописать в `assets/captions/NOTICE.md`. С первой секунды, под хуком приглушена (lowpass 420 Гц), раскрывается за 4 кадра перед склейкой
после хука (`L.music_open = кадр`). Музыка на 12 LU тише голоса, верх −5 dB от 5 кГц. Итог −14 LUFS, истинный пик ≤ −1 dB.
Всегда отдаются две версии: с музыкой и без.
