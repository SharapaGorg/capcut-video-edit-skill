# Каталог приёмов (`scripts/captions/kit.py`)

Раскладка — обычный python-файл `<проект>/auto/captions/layout.py`:

```python
import sys
from kit import Layout
L = Layout(sys.argv[1])            # читает words_on.json, heads.json, cuts.json из work/captions
F, w, front, back = L.F, L.w, L.front, L.back
...                                # блоки
L.music_open = <кадр склейки после хука>
L.build()
```
Все времена — КАДРЫ рендера (30 fps). `L.F(i)` — кадр слова i; `L.find("слово", start)` — номер слова по началу текста; `L.n` — число кадров;
`L.cuts` — жёсткие склейки. `front` — слой поверх человека, `back` — за человеком. Координаты — пиксели кадра 1080×1920.
Полный рабочий пример — `assets/examples/captions/layout_reel5_neurocreator.py`.

| Приём | Вызов | Когда и как |
|---|---|---|
| Слово субтитра | `w(text, кадр, cls, fx, out, style)` | cls: `sans` (Inter, белый 92 px) / `serif` (курсив, кремовый; размер задать в style) / `acc` (оранжевый) / `ink` (чернила, для силуэта). fx: `word` (подлёт), `pop`, `cut` (без анимации — для слова, которое уже звучит на склейке) |
| Фраза | `L.group(layer, y, f_out, [строка, строка], cls, x, width, style)` | строки — склейка `w()`. Вся фраза гаснет на `f_out` (обычно кадр первого слова следующей фразы). `x`/`width` — сдвинуть блок от головы или руки |
| Крупное слово за головой | `L.big(back, "СЛОВО", f, f_out, width, head_top=L.ht(f, f_out), ratio=0.5)` | ширина 700–930; `clip="top:0;height:960px"`, если камера в части кадра; в stills смотреть `cover` 0.05–0.35 и что слово читается |
| Крупное слово поверх | `L.big(front, "слово", f, f_out, width, top=y, cls="acc")` | в секциях без лица (над телефоном) |
| Рамка трекинга | `L.hud(f, f_out, "подпись ✓")` | крупный план анфас; печатает, на скольких кадрах найдено лицо — если меньше половины, приём не ставить |
| Силуэт | `L.silhouette(f, f_out, fill_y=None)` | + `L.eyes(f + 2, f_out)` обязательно, + заголовок `ink` в `back`, + две `L.ribbon` |
| Лента | `L.ribbon(back, f, f_out, "M … svg path")`, вторая половина `L.ribbon(front, f + 4, f_out, "…", reverse=True)` | путь рисовать вокруг человека: сзади через плечо, спереди по груди; концы уводить за кадр |
| Глаза | `L.eyes(f, f_out, blink=11)` | только на силуэте; проверить на stills, что сидят на глазах |
| Дьявол | `L.eyes(f + 2, f_out, devil=True)` + `L.devil(f + 3, f_out, size=1.15, tail=(x, y, scale))` | силуэт на имени знаменитости, «злодее» истории, конкуренте: рога растут из головы и следят за ней, хвост качается, глаза раскалённые и косые, сзади пульсирует красная виньетка. `tail` — точка на бедре с кадра. НЕ по умолчанию и не в каждом ролике: приём пользователю нравится («прикольная тема»), но «необязательно его везде тыкать» — редко, не в двух роликах подряд. Название чужого сервиса или бренда → его настоящий логотип на белой плашке (скачать с официального сайта, пример — раскладка рилса 7) |
| Кнопка-чип | `L.chip(y, f, f_on, f_out, [("только", f1), ("ИИ", f2)])` | «нажимаем», «включаем», «фильтр»; заливается на `f_on` |
| Прокрутка слова | `L.scroll(y, f, f_out, "листаем", lead="и")` | «листаем», «скроллим» |
| Печать адреса | `L.url("writelo.io", f, f_out, y, accent_from=7)` | ссылка или название сервиса; 16 кадров на набор, курсор, подчёркивание. На светлой стене — `bar=True` (тёмная плашка-адресная строка). Человек показывает пальцем — адрес ставить туда, куда показывает |
| Концовка с адресом | `extend.py base out 2.2 <кадр сетки>` → `prep --base out --force`; в раскладке сцена после последней склейки: `L.url(..., dur=1, size=190)` | ВСЕГДА, когда в CTA звучит «ссылка», «тут», «на сайте»: адрес остаётся один на экране 2–2.5 с, чтобы успели прочитать |
| Зачёркивание | `L.struck(w(...) + w(...), f_strike, f_out)` внутри строки | «без …», «не нужно …» |
| Закладка | `L.bookmark(f, f_out)` внутри строки | «сохраняй» |
| Строка на стыке сплита | `L.group(front, 944, f_out, [...], cls="sans seam")` | камера сверху, телефон снизу: мелкая строка 60 px на границе |
| Строка едет с краем | `L.ride_edge(f0, n, y, rest, html, f_out)` | первые кадры слайда: строка едет вместе с краем камеры до `rest` |
| Звук | `L.sfx("impact", кадр, -10)` | по таблице sound.md |

### Полноэкранные сцены (секция без камеры: в черновике тёмная сетка `grid_bg`, всё в `front`)
| Приём | Вызов | Когда и как |
|---|---|---|
| Счётчик | `L.counter(y, f, f_out, 100, dur=12, size=340)` | число из текста («разобрали 100…»); бежит от 0 |
| Сетка точек | `L.dots(y, f, f_out, n=100, cols=10, per=6, size=36, gap=10, hot_at=кадр)` | «100 аккаунтов», «каждый третий»: заполняется, с `hot_at` каждая `hot_every`-я точка оранжевая |
| Ряд плиток | `L.tiles(["ПН", …, "ВС"], f, f_out, pick=2, f_hot=…, f_dead=…)` внутри строки; обернуть в `L.struck(…)`, чтобы перечеркнуть | дни недели, часы, варианты: одна плитка загорается, потом ряд гаснет и зачёркивается («это не работает») |
| График | `pts = L.chart(f, f_out, [(x, y), …], dur, x, y, width, height)` | «всплески», «рост», «падение»; возвращает пиксели точек — подписи ставить `L.group(..., x=px - 250, width=500)` над пиками. Два пика под два слова — двумя вызовами (второй с `axis=False` продолжает первый) |
| Часы | `L.clock(y, f, f_out, size=360, speed=34)` | «время», «часы» |
| Стрелка | `L.arrow(f, f_out, size=150)` внутри строки | «в описании», «ниже» |
| Моно-подпись | `w()` со style `font-family:'JetBrains Mono'` | диапазоны, время («00:00 — 06:00»), номера пунктов на оранжевой плашке (`01`…`04`) |

Сцена = одна мысль: сверху мелкая строка гротеском, в центре главное слово (антиква `acc` 170–240 px или `big(front, …, top=…)`),
под ним проп. Центр композиции y ≈ 750–850, всё внутри y 290–1400. Следующая мысль заменяет сцену целиком склейкой.
Пример — `assets/examples/captions/layout_reel6_nike.py`, раскадровка `assets/examples/captions/reel6/`.

### Редакционный набор (референс 2, «красный монтаж»: REFERENCES.md)
Пример всех блоков на кадрах рилса 5 — `assets/examples/captions/layout_ref2_blocks.py`, кадры — `assets/examples/captions/ref2_blocks.jpg`.

| Приём | Вызов | Когда и как |
|---|---|---|
| Акцент ролика | `L.theme("red")` / `"violet"` / `"blue"` / `"#RRGGBB"` | акцентный цвет на весь ролик (слова, свечения, каракули, контур). По умолчанию оранжевый (бренд). Если в кадре свой сильный цвет (интерфейс сервиса, свет) — брать акцент оттуда: оранжевый рядом с синим или фиолетовым интерфейсом выглядит чужим (пользователь, 2026-11-17). Цвет снять пипеткой с кадра и поднять насыщенность, проверить читаемость на stills |
| Слова россыпью | `L.at(layer, w(...), x, y, f_out, rot=, ry=, align=)` | слово или строка в любой точке кадра: вокруг человека по ходу чтения (слева сверху → справа → вниз), каждому слову `font-size` в style. `rot` — наклон (акцентная фраза поперёк груди, −12…−18°), `ry` — разворот в перспективе (слова «лежат» на стене или экране, ±25…40°) |
| Лесенка | `L.stairs(layer, [(слово, кадр), …], x, y, f_out, size, grow, dx, accent=(i,))` | фраза ступеньками по диагонали, слово на строку. `grow` 1.25–1.45 — каждое следующее крупнее («и я пришлю ТЕБЕ»): для призыва и вывода. `grow` 1 + чередование белый/акцент — перечисление шагов |
| Заливка фона | `L.fill(back, f, f_out, цвет, halo=(cx, cy, r, цвет))` | комната заменяется цветом, человек остаётся цветным (вырезка на кремовом или красном). С `L.silhouette` — чёрная фигура на этом цвете; `halo` — светящийся диск за головой (центр — `L.head()`), так открывается ролик в референсе |
| Стена-слово | `L.wall(["СЛО", "ВО"], f, f_out, top, height)` | комната превращается в цветную стену, одно слово вытянутыми капителями от края до края, человек или предмет спереди. 0.4–0.7 с на ключевом термине. В сплите (камера в части кадра) `top`/`height` — по области камеры |
| Светящаяся карточка | `L.glowcard(f, f_out, [[("И ЭТО", f1)], [("ЖЕСТЬ", f2)]])` | чёрный экран, красные капители со свечением, строятся по словам. Одна на ролик, 0.8–1.2 с, на панчлайне хука |
| Каракули | `L.scribble(layer, kind, f, f_out, box, color, width, dur, seed)` | рисуются сами и «кипят». `circle` — обвести лицо или предмет (box от `L.FACE` после `L.track`), `arrow` — от подписи к предмету, `box` — грубая рамка вокруг объекта, `underline`, `cross`. Белым или акцентом; 1–3 на секцию, не на каждую фразу |
| Рукописный текст | `L.hand(layer, "твой\nстиль", f, f_out, x, y, size, rot)` | маркер (Caveat), пишется по буквам: личное слово («мой», «сам», «твой стиль»), пометка рядом с каракулей. На пустой стене или цветной заливке, 150–240 px. Не для обычных субтитров |
| Глитч-блоки | `L.blocks(f, f_out, n)` | чёрные/белые/акцентные прямоугольники мигают 6–10 кадров: самые первые кадры ролика или жёсткая склейка на новую главу |
| Угловые подписи | `L.meta(0, L.n, tl=, tr=, bl=)` | мелкие строки в углах на весь ролик: номер выпуска, тезис в две строки. Дают «журнальную» рамку; текст — из темы ролика, не выдуманные факты |
| Строка промта | `L.prompt("текст промта", f, f_out, y, dur, model=)` | стеклянная строка ввода, промт печатается: «пишу промт», «спросил у нейросети». В секциях без лица или внизу общего плана |
| Контур человека | `L.rim(f, f_out, color, width=7)` | обводка по маске акцентным цветом: человек «выделен» как объект — на названии продукта, оффере, CTA. Проверить на кадре, что маска чистая (волосы, предмет в руке) |
| Вспышка кадра | `L.flash(кадр, n=2, kind)` | 2 кадра на жёсткой склейке: `invert` — негатив, `white`, `duo` — двухцветный постер в акцентном цвете. Не чаще 2–3 раз за ролик |

### Окна с экранами сервиса (рилс 7, пример — `<проект>/auto/captions/layout.py`: `window()`, `phone()`)
Утверждение о продукте (цена, каталог, поиск, скидка, сравнение с конкурентом) = окно с НАСТОЯЩИМ экраном на стене за человеком (слой `back`), подписи уходят в боковые полосы стены.
- `window(картинка | html, f, f_out, x, y, width, url)` — окно браузера: вырезка из скриншота страницы (Playwright, popups скрыть, `device_scale_factor` 1.25–2). Текст в окне после масштаба ≥ 30 px, иначе вырезать уже.
- `flip(имя, t0, t1, f, f_out, crop)` — настоящий скринкаст в окне: на КАЖДЫЙ кадр ролика свой кадр исходника (нарезается ffmpeg при сборке раскладки), скорость ≤ ×2. Реже — «лагает» (отклонено пользователем).
- Источники: лендинг сервиса пользователя (видео `<video>` скачиваются напрямую), страница сравнения с конкурентом; официальный сайт конкурента — логотип, цена, формулировка. Экрана нет в открытом доступе → рисованная заглушка и сказать об этом пользователю.
- Где ставить: общий план в полный рост — тёмная панель на всю ширину в нижней части кадра (панель — нижняя ПОЛОВИНА кадра, верх y ≈ 1000: самый низ перекрывает интерфейс Instagram), окна внутри неё (`pwin`, `flip` в раскладке рилса 7). Панель заодно прячет низ комнаты (кровать). Сбоку/сверху от человека окна мелкие и «в пустоту» — пользователь это отклонил. Содержимое окон держать в y 1030–1540: ниже интерфейс Reels. На цветной стене (`L.wall`) панель выключать.
- Сравнение с конкурентом — таблица `table()` «параметр / мы / они», строки появляются на словах; цифры конкурента только с его официальных страниц (вся сетка тарифов, не «от N ₽» с лендинга).
- Угловые подписи `L.meta` на планах с окнами не ставить — пересекаются.

Композиция референса 2: в каждом плане текст стоит в НОВОМ месте и по-новому (за головой → россыпью → лесенкой → на стене → рукописно),
одно слово в 2–3 раза крупнее остальных и красное, остальные мелкие белые. Новый приём каждые 1–1.5 с.

## Сцены из реальных роликов (секции без камеры с советами и фактами)
Одобрено на рилсе 6 v6 (2026-11-18): «ролик намного лучше стал, когда поменяли визуал середины». Вместо иконок, часов, плиток и
нарисованных графиков каждая мысль показывается на НАСТОЯЩИХ роликах-примерах с настоящими цифрами. Пример —
`assets/examples/captions/reel6/scenes/` (scene1–3.py + keys_*.jpg), движок — `scripts/captions/footage_scene.py`.

Правила:
- Визуал ДОПОЛНЯЕТ озвучку новым фактом, а не повторяет её текстом: голос «забудьте про лучший день недели» → два рилса одного автора
  в один день недели и разница в просмотрах. Субтитров в таких сценах нет, текста на экране — 1–3 коротких метки.
- Цифры — только данные пользователя (брифа) и то, что видно в самих роликах. Не выдумывать даты, хэндлы, проценты; сравнение
  показывает разброс, а не причину — подписи нейтральные («разница в просмотрах», «к медиане просмотров аккаунта»).
- Ролики-примеры пользователь качает сам → `<рилс>/footage/<короткое_имя>.mp4`. Каждый просмотреть раскадровкой (1 кадр/с, затем
  10 кадров/с на кандидатах) и брать самый выразительный момент: меняющийся номер на футболке, приводнение капсулы ровно на слове
  «всплески», живые кадры матча; служебные белые вспышки и титры исходника пропускать (склейки внутри куска = frame skipping).
- Одна сцена = одна мини-история в 3 такта: карточки/видео → общий признак (оба «СРЕДА», оба 19:0x) → контраст (счётчики, полоски на
  ОДНОЙ шкале, нижний ролик тускнеет) → одна крупная цифра-итог Inter 900 ≈ 460 px акцентом, карточки уходят назад (яркость .3, blur 5).
- Композиции разные в каждой сцене: две вертикальные карточки рядом; наклонённая карточка с быстрыми склейками → две горизонтальные
  полосы с двух сторон; окно во весь верх со стоп-кадром + рамка-уголки на событии.
- Глитч — акцент 2–5 кадров, только на склейке между роликами и на появлении цифры: `rgb` (расслоение), `tear` (полосы вбок),
  `disp` (смещённые блоки); на цифре — в её области, затухает 26 → 3 px («стабилизация»). Без VHS, шума, неона.
- Фон сцены = кадры самого черновика (сетка ползёт, свечение) — сцена встаёт без шва; рисовать свою сетку не нужно.
- Лица: подписи и цифры не на лице (на стоп-кадре — плашка #0B0B0B 85 % под цифрой, подписи внизу окна). Людей по лицам не называть.
- Звук: появление карточки `swish2` + `thump` −13, склейки `cut_click`, глитч-переход `glitch2` −11, счётчик `counter` −12…−13,
  стоп-кадр `flash` −12; на цифре-итоге только `glitch2` −15 (не `impact`).

Как сделать:
1. `<рилс>/auto/scenes/sceneN.py` по образцу: `use(Path(__file__).parent)`, `Scene(name, f0, f1)` в кадрах рилса (границы — слова
   whisper, сцена занимает фразу целиком), `clip(src, t0, t1, n)` — n кадров исходника на n кадров рилса (скорость = длительность / n),
   `sc.footage(seq, f, box, parent=карточка)`, `sc.el(html, box, fin, fout, k={x, y, s, r, o, clip, blur, br, sat}, text={кадр: html})`,
   `sc.g(кадр, "rgb"|"tear"|"disp", box=…)`, `sc.sfx = [...]`.
2. `python -X utf8 sceneN.py --stills a,b,c` → `scenes/out/still_*.jpg`; поправить; полный рендер `python -X utf8 sceneN.py` →
   `scenes/out/<name>/%04d.jpg`, `<name>.mp4` (без звука), `sheet_<name>.jpg` — просмотреть.
3. В layout.py: убрать старые блоки этих фраз, оставив переменные кадров, и `L.plate(sc.f0, files)` + `L.sfx(*s)` для каждой сцены
   (блок «v5» в `layout_reel6_nike.py`). `L.plate` — готовые полные кадры идут в compose мимо браузера (сотни `<img>` 1080×1920 в
   gfx.html вешают Chromium по таймауту).
4. `run.py <auto> render --range <начало первой>,<конец последней> --name captions_vN`; отдельные mp4 сцен со звуком — вырезать из
   `captions_vN_music.mp4` по кадрам.

## Выбор приёма под фразу
- Вопрос или главный тезис хука → строка на стене + одно крупное слово за головой.
- Главное понятие ролика (существительное, 1–2 слова) в конце хука → силуэт.
- Название чужого сервиса, бренда, конкурента → его настоящий логотип (найти на официальном сайте) на белой плашке рядом с фразой; не силуэт и не рога.
- Крупный план перед силуэтом → HUD.
- Глагол действия в интерфейсе → проп (чип, прокрутка, печать).
- Перечисление («и по датам, и по цифрам») → каждое слово перечисления крупно за головой по очереди.
- Отрицание → зачёркивание. Призыв → крупно за головой + мелкая строка с иконкой.
- Панчлайн хука («и это жесть») → светящаяся карточка. Ключевой термин главы → стена-слово.
- Личное («мой», «твой», «сам») → рукописный текст; «вот это», «смотри сюда» → каракули (круг, стрелка).
- Вывод или призыв из 3–5 коротких слов → лесенка с ростом. Название продукта, оффер → контур человека + слово за головой.
- Совет / факт / наблюдение из исследования в секции без камеры («лучший день», «время», «всплески») → сцена из реальных роликов
  с настоящими цифрами (раздел выше), не иконки и не нарисованный график.
- Цифры и факты, для которых блока нет → крупная антиква `serif acc` 170–240 px; не изобретать новый блок без нужды, а если нужен —
  добавить в kit.py и сюда.

## Подводные камни
- Строка шире 1000 px вылезает за кадр молча: длинные слова антиквой (≥ 12 букв) — не крупнее 96 px либо отдельной строкой. Смотреть stills на обрезанные края.
- Голова двигается по кадру (крупный план с микрофоном в руке): слово за головой ставить высоко (ratio 0.6–0.7; ratio — доля буквы над макушкой), `head_top` — минимум `top` за время слова, а не медиана; короткое слово — сбоку от головы (`cx`).
- HUD и глаза: `track` печатает, на скольких кадрах найдено лицо. Меньше половины — HUD не ставить (в рилсе 6 на подвижном крупном плане 10 из 48 — убран).
  Глаза на общем плане работают: размер глаз сам масштабируется по лицу.
- Слова в words_on.json — как услышал whisper («ей тренды» вместо «ИИ-тренды»): текст писать руками из сценария, whisper даёт только времена.
- Склейки брать из `cuts.json` и раскадровки, не из плана черновика (план врёт на кадр).
- Слово, которое звучит на первом кадре после склейки, — `fx="cut"` и `max(F(i), кадр_склейки)`, иначе оно мелькнёт в предыдущей сцене.
- `L.ht(f0, f1)` — медиана верха головы за время слова; если человек встаёт или наклоняется, разбить слово на два отрезка или не ставить.
- Маска теряет человека на чёрных кадрах и секциях без камеры — там `back` бессмысленен, всё в `front`.
- Градиент ленты у каждого svg свой (делает `ribbon`); общий `id` в скрытом слое не рисуется.
