# Этап 6. Зумы + SFX
Место: после этапа 5.
Цель: направить взгляд и добавить динамики. Зум ничего не добавляет в кадр — только увеличивает.

## Перед началом
- Шаблоны: `assets/templates/keyframes_zoom.json` (ключевые кадры Scale/Position: вход, держание, выход), `sfx_segment.json`.
- Папка SFX — `config.json` → `sfx_dir` / `music_dir`.
- layout.json (STAGE_LAYOUT.md) — где S (скринкаст), где F (камера на весь экран).

## Типы
| Тип | Где | Когда | Параметры |
|---|---|---|---|
| Фокус | Скринкаст | Говорю про конкретный элемент экрана, он мелкий (< 1/4 ширины кадра) | ×1,5–2,0; центр — элемент; вход 350 мс, выход 300 мс; держать, пока говорю о нём (2–8 с) |
| Наезд | Камера на весь экран | Ключевая мысль, вывод | ×1,0→1,1 плавно за 2–3 с; без SFX; ≤ 1 за 2 мин |
| Punch-in | Камера на весь экран | Склейки из jumpcuts.json | Чередовать ×1,0 / ×1,15 по соседним сегментам; без анимации и SFX |

## Поиск фокуса
- В фразе назван элемент («кнопка Анализ», «поле поиска», «вот эта цифра») → OCR кадра в этот момент → bbox названного слова → центр зума.
- OCR не нашёл → посмотреть кадр (png), указать область. Не уверен → «под вопросом».
- При масштабе область целиком в кадре. Элемент под кружком камеры → сместить центр.

## Ограничения
- Фокус ≥ 2 с; между фокусами ≥ 8 с.
- Не на ускоренных кусках, не во время скролла.

## SFX
- Только на вход фокуса и вход/выход сплита. Выход зума — без звука.
- Старт SFX = старт анимации ±1 кадр.
- SFX = голос −12 LU (rules.md, «Звук»). Эффекты голоса на SFX не накладывать.
- Чередовать 2–3 звука, один и тот же подряд не ставить.
