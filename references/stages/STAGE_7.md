# Этап 7. Иллюстрации
«Я/мне» в тексте = пользователь; при делегированной автономии — решать самому, см. rules.md.
Место: после этапа 6.
Цель: показать то, чего нет на экране. Экран уже показывает, о чём речь → не иллюстрировать (это зум).

## Типы
| Тип | Когда | Вид |
|---|---|---|
| Схема | Объясняю процесс, связь, как устроено | Блоки + стрелки, появляются по мере речи |
| Список | Перечисляю 3–5 пунктов («во-первых», «три причины») | Пункты появляются в момент произнесения |
| Сравнение | A vs B, до/после, «у нас / у конкурентов» | Две колонки |
| Цифра | Называю число, статистику, цену | Крупное число #D46A40 + подпись ≤ 5 слов |
| Внешнее | Упоминаю сайт, ролик, сервис, которого нет на экране | Скриншот / картинка — материал от меня |
| Реакция | Шутка, ирония | Мем / картинка — только если дам материал |

## Размещение
- Камера на весь экран → сплит (rules.md, «Графика»): камера вправо, иллюстрация слева. Сплит — HTML-шаблон (graphics.md).
- Скринкаст → карточка поверх: ≤ 45% кадра, на плашке, с противоположной стороны от области, о которой речь; не перекрывает кружок.
- Дорожка иллюстраций: над скринкастом, под кружком камеры.

## Тайминг
- Начало = первое слово темы −0,2 с. Конец = последнее слово темы +0,5 с.
- ≥ 2,5 с и ≥ 0,3 с на каждое слово текста иллюстрации; ≤ 15 с (длиннее — разбить).
- Не одновременно с ключевой фразой (этап 8 обходит иллюстрации).
- Конфликт с фокус-зумом → в таблице предложить убрать зум.
- Карточки поверх скринкаста — в среднем не чаще 1 на 20 с.
