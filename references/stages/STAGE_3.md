«Я/мне» в тексте = пользователь; при делегированной автономии — решать самому, см. rules.md.
Место: после этапа 2 (и доп. этапов).
Цель: черновик на просмотр; единая карта таймкодов для этапов 4–10.

## Шаги
1. timeline_map.json — из файла проекта (источник истины — проект, не логи резки). Для каждого сегмента каждой дорожки: дорожка, файл, source_in/out, timeline_in/out, скорость, громкость.
2. Сверить с cuts_applied.json, cuts2_applied.json, assembly.json (если есть). Расхождения — в отчёт.
3. transcript_timeline.json: каждое слово → время таймлайна через карту. Слова вне оставленных сегментов — удалить (в dropped_words). Слова в ускоренных кусках остаются с полем speed (на ускорении голос заглушён — таких слов нет; есть только если ускорен кусок с голосом, например интро).
4. chapters_timeline.json: главы в новых таймкодах.
5. Отчёт: длительность; главы с таймкодами; оставшиеся «под вопросом».
6. **Стоп.** Я экспортирую черновик и смотрю. Присылаю правки: `мм:сс — что не так`.
7. Правки → применить → шаги 1–4 заново → отчёт. До моего «ок». Вырезка на всех дорожках: `scripts/stage3/ripple_cut.py --cuts cuts.json` (сам перегенерирует карты).

## Правила для этапов 4–10
- Все таймкоды — время таймлайна из transcript_timeline.json.
- Кадры брать из исходников через timeline_map.json, не из экспорта.
- Структурная правка → шаги 1–4 заново.

## Проверка
- VALIDATION.md.
- Каждое слово transcript_timeline попадает в сегмент голоса.
- 5 случайных слов: исходное время = (таймлайн − timeline_in) × скорость + source_in.
- Конец последнего сегмента = длительность проекта.
- Нет слов из вырезанных диапазонов.
