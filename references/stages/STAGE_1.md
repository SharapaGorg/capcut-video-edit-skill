# Этап 1. Смысловая резка
«Я/мне» в тексте = пользователь; при делегированной автономии — решать самому, см. rules.md.
Место: после этапа 0.
Цель: убрать лишнее по смыслу, разбить на главы.

## Перед началом
- Проект собран из свалки? Нет — этап 1 режет сырые дорожки; эффекты — на этапе 2 §7.
- Длительность таймлайна = длительность mp4, по которому сделана транскрипция. Не совпадает → стоп, сообщить. (Прогон по новому куску камеры — сравнивать с длительностью куска.)
- Бэкап проекта.

## 1. Транскрипт
- Читать готовые transcript.txt / .srt. Новый не собирать.
- Таймкоды фраз — только для поиска. Границы резки — строго по transcript.json (слова).

## 2. Кандидаты на вырезание
| Категория | Что |
|---|---|
| Дубль | Одна мысль сказана 2+ раза. Оставлять последний полный вариант; последний оборван или с оговоркой → лучший полный, указать какой |
| Фальстарт | Начатая и брошенная фраза |
| Служебное | Речь не для зрителя: «так, щас», «подожди», «где это», «записывается?» |
| Повтор | Уже объяснённое объясняется снова другими словами |
| Отступление | Не по теме ролика |
| Затянуто | Долгое описание того, что и так видно на экране |

- Содержательное не резать. Сомнение → «под вопросом».
- Кусок короче 1 с не предлагать (это этап 2).
- Для каждого кандидата: кадры скринкаста в начале и конце диапазона (png). Различаются → пометка «на экране действие».

## 3. Главы
- Глава = смысловой блок, обычно 2–8 мин. Делить по смене темы, не по времени.
- Требование YouTube (иначе главы не включатся): первая с 00:00, минимум 3, каждая ≥ 10 с.
- Название ≤ 5 слов.

## 5. Применение
- Утверждённое → cuts_approved.json: `[{id, start_us, end_us}]` во времени транскрипта.
- Границы по словам, отступ ≥ 80 мс, не внутри слова.
- Резать все дорожки синхронно: камера, скринкаст (видео и звук), mp3, Adjustment.
- Без дыр: всё после вырезки сдвигается влево.
- cuts_applied.json: что вырезано и сдвиг каждого оставшегося куска.
- chapters.json: главы во времени транскрипта.
