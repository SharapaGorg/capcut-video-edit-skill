# Этап 9. Музыка
«Я/мне» в тексте = пользователь; при делегированной автономии — решать самому, см. rules.md.
Место: после этапа 8 (структура финальная).
Цель: тихая подложка, которая не мешает голосу.

## Перед началом
- Треки — из папки музыки (`config.json` → `music_dir`). Только с правом использования на YouTube (YouTube Audio Library и подобное) — иначе Content ID.
- По умолчанию `apply_music.py` берёт один трек — первый файл `music_dir` по имени (выбор печатается). Другие треки: `--files ИМЯ …` (в порядке звучания, по одному на главу или группу глав) или `--tracks N` (первые N файлов).
- Deep — шаблон `assets/templates/deep_effect.json` (поиск в кэше по resource_id, capcut-format.md).

## Где и как громко
| Участок | Уровень |
|---|---|
| Под речью | На 13 LU тише голоса |
| Без речи ≥ 2 с (ускорения, паузы) | +6 dB к уровню под речью |
| Последние 20 с (конечная заставка) | На 10 LU тише голоса (исключение из −13 LU); затухание 2 с в конце |

- Переходы громкости — рампы 300 мс двумя треками с перекрытием (capcut-format.md).
- Эффект Deep на все куски музыки (клон шаблона).

## Склейка
- Зацикливать по границам тактов (beat tracking), без щелчков.
- Смена трека — только на границе главы, кроссфейд 2 с.

## Применение
- Отдельная аудиодорожка. Ключевые кадры громкости по таблице уровней.

## Проверка
- VALIDATION.md.
- В местах речи музыка тише голоса на 13 ±2 LU (измерить по окнам 3 с).
- Конец — затухание, не обрыв.
- Склейки циклов — на границах тактов.
