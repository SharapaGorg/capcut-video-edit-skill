# Этап 10. Экспорт и YouTube
Место: последний.
Цель: финальный файл с нормальной громкостью и всё для загрузки.

## Экспорт
1. Сообщить мне разрешение и fps проекта. Экспорт делаю я в CapCut: то же разрешение и fps, H.264, битрейт высокий.
2. Громкость: ffmpeg ebur128 → −14 LUFS ±1, true peak ≤ −1 dBTP. Иначе — loudnorm в два прохода, видео копировать без перекодирования → `<имя>_final.mp4`.

## Для YouTube
- chapters.txt: `мм:сс Название`. Первая 00:00, минимум 3, каждая ≥ 10 с. Таймкоды — по финальному файлу.
- subtitles.srt — из transcript_timeline.json: строка ≤ 42 символа, ≤ 2 строки, блок 1–7 с, слова не разрывать, орфография проверена. Загружаю в YouTube как субтитры, в видео не вшивать.
- Описание: мой файл, путь — `config.json` → `description_md`. Заменить в нём только блок таймкодов на содержимое chapters.txt, остальной текст не трогать. Блока таймкодов нет → добавить в конец и сообщить. Файла нет → спросить, не генерировать.

## Порядок после экспорта
- `scripts/stage10/loudnorm.py "<экспорт>.mp4"`: ffprobe → ebur128 → при выходе за норму двухпроходный loudnorm (видео copy, aac 320k) → `<имя>_final.mp4` → повторный замер → кадры раз в 10 с → 5 реплик srt через whisper ±0.3 с → `stage10/export_report.md`, код 0/1. Флаги `--dry`, `--no-whisper`.
- Экспорт (делаю я): 1920×1080, 30 fps, H.264, битрейт ≥ 16 Мбит/с, AAC 48 кГц. Перед открытием проекта для экспорта — `Get-Process CapCut` = 0 после последней записи.
- На YouTube: `_final.mp4` (если создан, иначе исходный), srt — Subtitles → Upload file → With timing; длительность экспорта ≠ таймлайн > 0.5 с → пересобрать srt со сдвигом. Главы — в описание.
- Превью и загрузка — не в скилле.

## Проверка
- ffprobe: разрешение и fps = проект; длительность аудио = видео ±1 кадр.
- Громкость в норме (после loudnorm — измерить повторно).
- Кадры раз в 10 с (png): нет неожиданных чёрных кадров (средняя яркость < 3%), нет плашек отсутствующих медиа.
- Главы и srt — по финальному файлу: 5 случайных реплик srt совпадают со звуком ±0,3 с.
