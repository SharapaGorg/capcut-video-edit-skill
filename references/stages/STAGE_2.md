# Этап 2. Техническая резка
«Я/мне» в тексте = пользователь; при делегированной автономии — решать самому, см. rules.md.
Место: после этапа 1.
Цель: паузы, паразиты, шумы, служебные кадры, ускорение скучного скринкаста.

## Параметры
| Параметр | Значение |
|---|---|
| Отступ от слова до склейки | 80 мс |
| Пауза внутри предложения → оставить | 150 мс |
| Пауза между предложениями → оставить | 300 мс |
| Пауза между главами → оставить | 600 мс |
| Паузу короче — не трогать | 300 мс |
| Минимальная длина сегмента после резки | 300 мс |
| Ускорение скринкаста | ×2–×8, целевая длительность 1–2 с |

## Перед началом
- Этап 1 применён и проверен, cuts_applied.json есть.
- Решения — во времени транскрипта. В координаты таймлайна переводить через cuts_applied.json только при применении.
- Бэкап проекта.

## 1. Границы слов
- Таймкоды whisper неточные (±100 мс).
- Каждую границу уточнять по звуку голоса: в окне ±150 мс от границы слова найти минимум RMS (окно 10 мс), резать там.
- Минимум на звучащей речи → не резать, «под вопросом».

## 2. Паузы
- Пауза = от конца слова до начала следующего. Сокращать по таблице. Тип — по пунктуации; граница главы — по chapters.json.
- Не сокращать, если в паузе на скринкасте действие (кадры раз в 0,5 с различаются) → раздел 5.
- Громкий вдох в оставляемой части → вырезать или −15 dB.
- Склейки внутри кусков камеры → jumpcuts.json. На этапе 6 их маскируют punch-in.

## 3. Паразиты и хезитации
- «э», «эм», «ммм» whisper часто не пишет. Искать по звуку: участок ≥ 250 мс с энергией голоса без слов в JSON → вырезать автоматически.
- Тянущиеся гласные внутри слова не трогать.
- «ну», «вот», «типа», «короче», «как бы», «в общем», «значит»: в начале фразы после паузы, без смысла → вырезать; внутри фразы → «под вопросом».
- После вырезки соседние паузы нормализовать.

## 4. Шумы
- Пики энергии вне слов: кашель, чих, стук, клики, сглатывание. В паузе → вырезать. Поверх слова → «под вопросом».

## 5. Скринкаст: служебное и ускорение
- Кадры раз в 0,5 с; отдельно первые и последние 5 с каждого исходного куска.
- Служебное → вырезать: окно программы записи, старт/стоп, постороннее окно, пустой рабочий стол.
- Ускорение: на экране действие (загрузка, ввод, скролл) и нет речи ≥ 3 с.
  - Коэффициент = длительность / 1,5 с, в пределах ×2–×8. Нужен > ×8 → вырезать середину.
  - Звук ускоренного куска заглушить.
- Речь поверх действия → не ускорять. Камеру не ускорять.

## 6. Применение
- «Авто» — применить сразу.
- «Под вопросом» → stage2_review.md: таймкод, текст ±3 слова, категория, причина. **Стоп** по этим пунктам, отвечаю номерами.
- Резать все дорожки синхронно: камера, скринкаст (видео и звук), mp3, Adjustment. Без дыр.
- Сегменты короче минимума — слить с соседним.
- cuts2_applied.json: вырезки и ускорения во времени транскрипта.

## Проверка
- VALIDATION.md.
- Ни одна склейка не ближе 80 мс к слову.
- Ускоренные куски: голос заглушён.
- 10 случайных склеек: звук ±2 с вокруг склейки → whisper (tiny) → слова совпадают с транскриптом. Обрезанное или лишнее слово → провал.
- Отчёт: было/стало; число склеек; секунд убрано по категориям; число ускорений и сэкономленные секунды.

## 7. После резки: сборка (обязательно, в этом порядке; одним скриптом — `scripts/stage2/assemble.py`)
0. Синхронизация камеры со звуком скринкаста/микрофона — кросс-корреляция огибающих (`scripts/layout/xcorr.py`), 3 контрольные точки, ≤ 1 кадр. Кружок: маска Circle, позиция/масштаб — из шаблонов (STAGE_LAYOUT.md, A2).
   Недостающий кусок камеры (опционально): файл камеры есть в исходниках, но не на таймлайне → кросс-корреляция звука камеры с исходниками голоса (16 кГц моно, огибающая). Пик чёткий → положить камеру на те же исходные диапазоны (+ смещение), наследует вырезки этапов 1–2; синхрон 3 точки ≤ 1 кадр; звук камеры 0 (`scripts/layout/add_camera.py`). Пика нет → кусок новый: этапы 0–2 по нему, место вставки по смыслу, всё после сдвинуть; сохранить assembly.json (случай, файл, смещение/точка, длительность).
1. Compound clips (`stage2/make_compound.py`): микрофон → 1, камера во весь кадр → 1 на участок, скринкаст → 1, кружок камеры → 1. Камеру во весь кадр и скринкаст в один клип не смешивать.
2. Звук камеры выключить: volume 0 на compound-сегментах камеры (во весь кадр и кружок). Голос только с микрофона и скринкаста.
3. Эффекты голоса (Reduce noise + Voice Crisper, шаблон `assets/templates/`) — на compound-сегменты микрофона и скринкаста.
4. Adjustment: один блок на весь участок камеры во весь кадр (не резаный, растянутый по границам участка; на каждый такой участок). Свалка с уже стоящими блоками Adjustment → assemble.py отказывает (цвет дважды); удалить их и запустить снова.
5. Кружок камеры: Temp −18, Saturation 10 прямо на compound-сегмент кружка (делает assemble.py; проверка/починка — `scripts/layout/fix_circle.py`).
6. Проверка: на дорожках 3–5 сегментов; звук камеры 0; у голосовых сегментов есть audio_effects + realtime_denoises; Adjustment покрывает участок камеры целиком.
