# Правила монтажа

## Правила
- Перед правкой: `Get-Process CapCut` = 0 (иначе `Stop-Process -Name CapCut -Force`, проверить 0), папка проекта скопирована в `backups/<этап>-before-<stamp>`. Правки не видны → перезапустить CapCut.
- Закрытый проект при живом процессе — не закрыт: CapCut перепишет файл из памяти через 1–20 мин. Пользователь говорит «закрыл» про проект — не спорить, убить процесс самому.
- Автообновление CapCut выключено.
- Настоящий таймлайн — `Timelines/<id>/draft_content.json`. Корневой `draft_content.json` — зеркало, CapCut перезаписывает его при открытии. Любой скрипт пишет в ОБА файла (+ subdraft), `update_time` обновить (`scripts/common.py`).
- Guard: перед чтением запомнить mtime draft_content.json; через 5 с после записи mtime не изменился. Изменился → CapCut жив, стоп.
- Новые эффекты/материалы не создавать с нуля: клон шаблона `assets/templates/` или существующей записи (deepcopy + новый UUID upper). Все id в extra_material_refs существуют в materials.
- Python только `python -X utf8`. У каждого скрипта записи `--dry`. Патчи — файлом, не bash-heredoc (на Windows длинный heredoc ломается).
- Исходники не копировать и не переименовывать: пути из `config.json` → `sources`.
- Этапы — строго по порядку. Каждый этап — свой файл `stages/STAGE_N.md`, проверки этапа — в конце его файла, общие — validation.md. Провал проверки → не идти дальше, отчёт.
- «Стоп» в файле этапа → решать самому, консервативно; записать в proposal-файл и PROGRESS.md «утверждено автоматически» + причина. Исключения (нужен ок пользователя): черновик этапа 3, тестовая графика этапа 7–8, первый шортс.
- Не спрашивать то, что можно определить по данным (кадры, замеры).
- После этапа 3 все таймкоды — время таймлайна по timeline_map.json и transcript_timeline.json. Любая правка структуры (вставка, вырезка, сдвиг) → перегенерировать их (`scripts/stage3/build_maps.py`, STAGE_3.md шаги 1–4) + validation.
- Таймкоды whisper на склейках ненадёжны: границы сверять по звуку (ffmpeg astats, RMS 10 мс).
- Не ждать вхолостую: длинные задачи (whisper, ffmpeg) в фоне с логом, проверить прогресс в течение минуты; > 5 мин → ускорить (батч). Фоновые циклы-ожидания после отмены — убивать.
- Отчёт этапа: раздел в PROGRESS.md (что сделано, скрипты, бэкапы, результаты проверок фактически, решения вместо пользователя с обоснованием).
- fps 30, 1920×1080 (из config). Время в проекте — микросекунды.

## Звук
- Источник голоса: во вступлении — mp3 микрофона (`sources.voice`), если есть; дальше везде — звук самих клипов скринкаста. «Звук голоса» во всех инструкциях = эти два источника.
- Нет микрофона → голос со скринкаста везде. Звук камеры — никогда: volume 0, только для синхронизации.
- Громкость голоса выровнять между источниками: измерить LUFS mp3 и звука скринкаста, Volume подобрать так, чтобы совпадали (±1 LU). +4.5 dB — только для mp3.
- Голос (все куски голоса): Basic → Reduce noise, Voice changer → Voice filters → Voice Crisper (Strength 100). Шаблоны `voice_crisper.json`, `reduce_noise.json`.
- Музыка: Voice changer → Voice filters → Deep (шаблон `deep_effect.json`).
- Уровни: SFX / звук вставок = голос −12 LU; музыка под речью = голос −13 LU; финал −14 LUFS, true peak ≤ −1 dB. Значения в dB сообщать пользователю.
- SFX: `config.json` → `sfx_dir`. Музыка: `config.json` → `music_dir`, только с правом использования на YouTube.

## Цвет
- Цветокор: отдельный блок Adjustment на дорожке над видео. Adjust → Temp −18, Saturation 10, остальное 0.
- Блок Adjustment только над кусками камеры на весь экран. Не резать: один непрерывный блок на весь участок, на каждый такой участок свой. Скринкаст не трогать.
- Камера кружком поверх скринкаста: те же значения в Adjust на самом клипе, не блоком.
- Маска: материал common_mask должен быть type "mask", category "video", path в существующую папку Cache/effect (круг — ищется по resource_id). type "none" / несуществующий path → CapCut маску молча игнорирует (прямоугольник).

## Графика
- Только HTML → Playwright → ProRes 4444 MOV → видеоклип в CapCut (graphics.md). Текст CapCut, PIL, Remotion — запрещены. Замена инструмента = вопрос пользователю.
- Шрифт: Unbounded. Основной цвет текста — белый.
- Акцент: #D46A40. Только ключевое слово, стрелки, рамки, цифры. Не заливки.
- Плашка: #0A0A0A, непрозрачность 85% (D9).
- Текст поверх камеры — только на плашке. Стена светлая: белый и оранжевый без плашки не читаются (контраст < 2).
- Оранжевый — только на плашке и не рядом с лицом (близок к тону кожи, сливается).
- Других цветов нет.
- Сплит: справа кроп камеры (≈35–85% ширины исходника, во всю высоту), слева сплошной фон #0A0A0A с иллюстрацией. Вход/выход — сдвиг 400 мс + SFX.

## Что есть что
| Слой | Что это | Как отличить |
|---|---|---|
| Зум | Увеличение части экрана или камеры | Ничего не добавляет, направляет взгляд |
| Иллюстрация | Схема, список, сравнение, цифра, внешняя картинка | Новая визуальная информация, которой нет на экране. Без неё зритель хуже поймёт |
| Ключевая фраза | Текст ≤ 6 слов на плашке | Дублирует сказанное. Без неё поймёт, с ней запомнит |
| Заставка главы | Номер + название главы, 2,5 с | Только в начале глав |
| Субтитры | Полный текст речи | В видео не вшиваются. Файл .srt для YouTube |

## Compound clips
- После резки (этап 2) объединять одинаковое в compound clip: микрофон → 1, камера во весь кадр → 1 на участок, скринкаст → 1, кружок → 1. Иначе проект лагает от сотен кусочков. Имена/id — в `config.json` → `compounds`.
- Не смешивать в одном compound камеру во весь кадр и скринкаст.
- Структура (вложенный draft в materials.drafts, папка subdraft, запись в draft_meta_info) — `scripts/stage2/make_compound.py`, capcut-format.md.
- Эффекты голоса, Adjustment и цвет на кружок — ПОСЛЕ объединения, на compound-сегменты (3–4 куска вместо сотен).
- Дальнейшая резка — внутри вложенных драфтов (materials.drafts[].draft) или раскрыть compound.
- АУДИО-compound CapCut пререндерит в `Resources/combination/<combination_id>_audio.aac` (путь в `subdraft/<id>/sub_draft_config.json` → audio_path). После любой правки внутри такого compound: удалить этот .aac и очистить audio_path, иначе CapCut играет старый звук → рассинхрон. Видео-compound не пререндерится.

## YouTube-заголовки
- Короткий вопрос в форме поискового запроса: «Как …» / «Почему …» / «Что …», 5–8 слов, ≤ ~60 знаков, слова ниши. Не дубль хука, не длинный остроумный тезис. 3–4 варианта, рекомендовать один.
