# TikTok — как вести на длинный ролик

Кликабельной ссылки нет до 1000 подписчиков → ведём через поиск YouTube.

## Длина
- ≤ 15 с — тизер: хук + одна мысль (речь 7.5–12.5 с) + карточка 3 с.

## Финальная карточка (3 с)
- Скрин превью длинного ролика в выдаче YouTube (`tiktok_card.png`, даёт пользователь) с названием.
- Плашки: «ПОЛНОЕ ВИДЕО НА YOUTUBE» + «ИЩИ ПО НАЗВАНИЮ ↑»; когда известно имя канала — «Полное видео на YouTube: <канал>» (проверить, что в поиске YouTube без аккаунта канал первый).
- Тот же текст — в описании и в закреплённом комментарии.
- Ссылки на сервисы на карточку не ставить — только в описании длинного ролика.
- С 1000 подписчиков: ссылка в профиль, текст → «ссылка в профиле».

## Сборка
- `python -X utf8 scripts/shorts/build.py <id> --tiktok` → `out/tiktok/<id>_<slug>.mp4`. Диапазоны — блок `tiktok.ranges` в спеке.
- Имя канала — `TIKTOK_CHANNEL` в config.json; появилось → пересобрать (`--no-render` нельзя).
- Отвечать строго про TikTok, не примешивать Shorts/Reels.
