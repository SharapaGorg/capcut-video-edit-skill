# TikTok — как вести на длинный ролик

Кликабельной ссылки нет до 1000 подписчиков → ведём через поиск YouTube.

## Длина
- ≤ 15 с — тизер: хук + одна мысль (речь 7.5–12.5 с) + карточка 2.5 с. Больше 15 с с карточкой → сборка останавливается после плана.

## Финальная карточка (2.5 с)
- Скрин превью длинного ролика в выдаче YouTube с названием — `tiktok_thumbnail` в config.json (даёт пользователь; не задан → карточка без скрина, предупреждение).
- Плашка «Полное видео на YouTube: <канал>» (`tiktok_channel` в config.json; проверить, что в поиске YouTube без аккаунта канал первый). Канал не задан → «ПОЛНОЕ ВИДЕО НА YOUTUBE» + «ИЩИ ПО НАЗВАНИЮ ↑», сборка предупреждает; имя не выдумывать.
- Тот же текст — в описании и в закреплённом комментарии.
- Ссылки на сервисы на карточку не ставить — только в описании длинного ролика.
- С 1000 подписчиков: ссылка в профиль, текст → «ссылка в профиле».

## Сборка
- `python -X utf8 scripts/shorts/build.py <id> --config config.json --tiktok` → `out/tiktok/<id>_<slug>.mp4`. Динамичный режим: паузы 0.12 с, хук 1.5 с, панч-ин ×1.18 на каждой второй склейке + тихий вуш, субтитры с пружинкой. Диапазоны — блок `tiktok.ranges` в спеке.
- Имя канала — `tiktok_channel` в config.json; появилось → пересобрать (`--no-render` нельзя).
- Отвечать строго про TikTok, не примешивать Shorts/Reels.
